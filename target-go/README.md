# Target Go – Backend Setup Guide

## Prerequisites (install these first)

| Tool | Download |
|------|----------|
| Java 17 JDK | https://adoptium.net |
| Maven | https://maven.apache.org/download.cgi |
| MySQL | https://dev.mysql.com/downloads/installer/ |
| IntelliJ IDEA (Community is free) | https://www.jetbrains.com/idea/download/ |

---

## Step 1 – Set Up MySQL

1. Install MySQL and open MySQL Workbench (or the command line)
2. Create the database:
```sql
CREATE DATABASE targetgo;
```
3. Note your MySQL username and password

---

## Step 2 – Configure the App

Open `src/main/resources/application.properties` and update:

```properties
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD_HERE
```

---

## Step 3 – Run the App

### Option A: IntelliJ (easiest)
1. Open the `target-go` folder in IntelliJ
2. Let it import the Maven project (bottom progress bar)
3. Open `TargetGoApplication.java`
4. Click the green ▶ Run button

### Option B: Terminal
```bash
cd target-go
mvn spring-boot:run
```

You should see:
```
✅ Seeded 15 products.
Started TargetGoApplication on port 8080
```

---

## Step 4 – Test the API

Use **Postman** (free at postman.com) or the VS Code extension **Thunder Client**.

### Register a user
```
POST http://localhost:8080/api/auth/register
Content-Type: application/json

{
  "email": "test@email.com",
  "password": "password123",
  "firstName": "John",
  "lastName": "Doe"
}
```
→ Returns a `token` — copy it!

### Login
```
POST http://localhost:8080/api/auth/login
Content-Type: application/json

{
  "email": "test@email.com",
  "password": "password123"
}
```

### Browse Products (no login needed)
```
GET http://localhost:8080/api/products
GET http://localhost:8080/api/products?search=iphone
GET http://localhost:8080/api/products?category=Electronics
```

### Add to Cart (requires token)
```
POST http://localhost:8080/api/cart/add
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "productId": 1,
  "quantity": 2
}
```

### View Cart
```
GET http://localhost:8080/api/cart
Authorization: Bearer YOUR_TOKEN_HERE
```

### Checkout / Pay
```
POST http://localhost:8080/api/orders/checkout
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "cardNumber": "4111111111111111"
}
```
→ Returns your order with confirmation number

Use card `4000000000000002` to simulate a declined card.

### View Order History / Receipt
```
GET http://localhost:8080/api/orders
GET http://localhost:8080/api/orders/1
Authorization: Bearer YOUR_TOKEN_HERE
```

## API Endpoints Summary

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| POST | /api/auth/register | No | Create account |
| POST | /api/auth/login | No | Login, get JWT token |
| GET | /api/products | No | List all products |
| GET | /api/products?search= | No | Search products |
| GET | /api/products?category= | No | Filter by category |
| GET | /api/products/{id} | No | Get single product |
| GET | /api/cart | Yes | View cart + total |
| POST | /api/cart/add | Yes | Add item to cart |
| PUT | /api/cart/{itemId} | Yes | Update quantity |
| DELETE | /api/cart/{itemId} | Yes | Remove item |
| DELETE | /api/cart | Yes | Clear cart |
| POST | /api/orders/checkout | Yes | Checkout + payment |
| GET | /api/orders | Yes | Order history |
| GET | /api/orders/{id} | Yes | Get receipt |

## Project Structure

```
src/main/java/com/targetgo/
├── TargetGoApplication.java     ← Entry point
├── models/
│   ├── User.java
│   ├── Product.java
│   ├── CartItem.java
│   ├── Order.java
│   └── OrderItem.java
├── repositories/                ← DB access (auto-generated by Spring)
├── services/
│   ├── CartService.java         ← Cart business logic
│   ├── OrderService.java        ← Checkout + order history
│   └── PaymentService.java      ← Payment simulation
├── controllers/                 ← REST API endpoints
│   ├── AuthController.java
│   ├── ProductController.java
│   ├── CartController.java
│   └── OrderController.java
├── config/
│   ├── SecurityConfig.java      ← Route protection rules
│   ├── JwtUtil.java             ← Token generation/validation
│   ├── JwtFilter.java           ← Runs on every request
│   └── DataSeeder.java          ← Seeds 15 sample products
└── dto/
    ├── RegisterRequest.java
    └── LoginRequest.java
```
